# Changelog

## 0.1.0 — 2026-10-23

- Created a Python/FastAPI campus taxi foundation without ROS.
- Added simulation route planning, latched fault handling and explicit recovery.
- Added dashboard, telemetry, trip/event persistence and operator-token checks.
- Added ESP32-CAM camera/telemetry and Arduino disarmed bench firmware starters.
- Added tests, CI, VS Code configuration, hardware/protocol docs and Codex instructions.
- Physical driving remains unimplemented and unavailable.
